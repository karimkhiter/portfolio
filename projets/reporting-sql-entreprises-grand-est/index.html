SAÉ 1.01 · Semestre 1 · individuel

Interroger une base d’entreprises du Grand Est en SQL

Requêtes SQL sous DuckDB (filtres, jointures), puis tableaux croisés dynamiques Excel pour un reporting sur les entreprises de la région.

Période
Semestre 1 · automne 2024
Type
SAÉ
Équipe
Individuel
Statut
Terminé

Le problème

Comment extraire les bonnes informations d’une base relationnelle aux données hétérogènes, et en faire des tableaux de bord filtrables ?

Contexte

Base de données des entreprises du Grand Est fournie par l’enseignant, avec un cahier des charges à respecter.

La démarche

  1. Intégrer

    Chargement de la base dans DuckDB, un moteur SQL analytique léger.

  2. Interroger

    Sélections par secteur, taille ou localisation, filtres par code NAF, jointures, gestion des valeurs manquantes et des doublons.

  3. Restituer

    Exports CSV et tableaux croisés dynamiques Excel.

Livrables

  • Requêtes SQL
  • Tableaux croisés dynamiques

Limites

  • À l’époque, les jointures restaient difficiles sans le cours sous les yeux.

Ce que j’en retiens

La qualité d’un tableau de bord dépend d’abord de la requête qui l’alimente : une jointure mal pensée produit des indicateurs trompeurs.
