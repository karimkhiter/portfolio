SAÉ 3.VCOD.01 · Semestre 3 · équipe de 4

Collecter automatiquement un catalogue de produits en ligne

Un script Python (Playwright, Pandas) qui parcourt les fiches produits d’une marque d’alimentation animale, nettoie les informations et les exporte selon un schéma commun.

Période
Semestre 3 · janvier 2026

SAÉ 3.VCOD.01Data · Applications

Le problème

Comment récupérer proprement des données produits sur un site au contenu dynamique, pour alimenter ensuite un entrepôt de données ?

Contexte

Chaque groupe était responsable d’une marque ; la nôtre était Blue Buffalo. Le script tournait sur Google Colab.

La démarche

  1. Naviguer comme un utilisateur

    Playwright plutôt qu’une simple requête HTTP, car le site charge son contenu en JavaScript ; attentes explicites sur les éléments de la page.

  2. Extraire et normaliser

    Nom, prix, ingrédients, poids, image. Les textes sont nettoyés : « 20 lbs » devient une valeur et une unité exploitables.

  3. Gérer l’hétérogénéité

    Des fiches structurées différemment, des champs parfois absents : conditions et gestion d’erreurs pour produire des valeurs nulles sans interrompre la collecte.

  4. Respecter le site

    Délais entre les requêtes, respect du fichier robots.txt, export CSV conforme au schéma commun à tous les groupes.

Livrables

  • Notebook de collecte commenté
  • Fichier CSV au schéma imposé

Résultats

  • Un jeu de données structuré, prêt à être intégré avec ceux des autres marques.

Limites

  • Livrables pas encore publiés : nettoyage du code en cours.

Ce que j’en retiens

Concevoir la structure du fichier de sortie avant d’écrire le code évite de tout reprendre ensuite.
