SAÉ 3.02 · Semestre 3 · binôme

Alimenter un entrepôt de données avec le Journal officiel

Une chaîne ETL sous Apache HOP qui extrait les annonces d’associations du JOAFE (XML), les nettoie et les charge dans une base relationnelle modélisée pour l’analyse.

Période
Semestre 3 · automne 2025
Type
SAÉ
Équipe
Binôme
Statut
Terminé
SAÉ 3.02Data

Le problème

Comment transformer des milliers d’annonces XML imbriquées en tables propres, interrogeables par des requêtes analytiques ?

Contexte

Données ouvertes du Journal officiel des associations (JOAFE) : créations, modifications et dissolutions d’associations en France.

La démarche

  1. Extraire

    Requêtes XPath pour isoler les informations utiles (nom, date, objet de l’association) dans des fichiers XML très imbriqués.

  2. Transformer

    Pipeline Apache HOP : gestion des dates manquantes, uniformisation de la casse, règles de gestion avant insertion.

  3. Modéliser et charger

    Conception du modèle (MCD, MLD) et correspondance entre les flux transformés et les tables, clés primaires et étrangères comprises.

Livrables

  • Pipeline Apache HOP
  • Base relationnelle
  • Documentation technique et requêtes analytiques

Résultats

  • Plus de 3 000 annonces intégrées dans une base centralisée.

Limites

  • Pipeline fonctionnel mais lent, faute de temps pour l’optimiser.
  • Pas de chargement incrémental : l’entrepôt ne se mettait pas à jour seul à l’arrivée de nouveaux fichiers.

Ce que j’en retiens

Penser l’architecture complète, extraction et mise à jour, avant de plonger dans le détail. Un ETL qui ne se met pas à jour n’est pas prêt pour la production.
